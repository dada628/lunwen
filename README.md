# 算法题自动难度预测：因子设计、捷径依赖与零样本基线

本仓库是论文《面向程序设计教学的算法题自动难度预测》的**可复现材料**，包含实验代码、
已处理数据集、聚合结果与绘图脚本。论文正文未随仓库发布。

## 一句话结论

在同一划分与同一调参预算下比较 10 个模型与 3 个零样本大语言模型，发现：
存量题库场景下梯度提升树（LightGBM）的平均绝对误差最低（157.69）；
但该优势主要来自标签与提交统计的**同源成分**——仅用 3 个元数据字段即可兑现
来源特征总收益的 **98.1%**，说明当前精度中相当部分由**结构性捷径**兑现，
题面文本的独立贡献有限。

## 数据说明

**为什么仓库里没有原始数据**

`data/raw/` 约 1.5 GB，其中单文件 `statements.jsonl` 达 735 MB，
超过 GitHub 单文件 100 MB 的硬限制。因此：

- 仓库内提供**已处理数据集** `data/processed/dataset.csv`（17 MB），
  含全部 11 080 道题的特征与标签，**足以复现论文中的全部实验结果**；
- 如需从零重建原始快照，运行 `python download_data.py`（走 Codeforces 公开 API，无需密钥）。

**快照日期**：2026-10-06。Codeforces 的 rating 与累计通过人数会随时间演化，
晚于该日期重建的数据与论文不完全一致——这是排行榜类数据的固有性质。

## 实验设计要点

- **因子设计**：划分方式（随机 / 时间）× 特征可得性（统计特征全量 / 置空）→ 四格 A/B/C/D
- **公平协议**：所有模型共用同一份 `split_index.csv`；同一调参预算；测试集只用一次
- **多次运行**：5 个随机种子（部分格 3 个），报告均值±标准差
- **显著性检验**：配对自助法（10⁴ 次），报告 95% 置信区间
- **泄漏显式标注**：C 格为乐观泄漏上界，不作部署依据
- **弱基线**：含朴素基线（标签均值）与仅用来源特征的弱基线

## 主要结果

| 格 | 含义 | LightGBM MAE |
|---|---|---|
| A | 随机划分 + 统计特征全量（存量题库） | 157.69 |
| B | 随机划分 + 统计特征置空 | 376.41 |
| C | 时间划分 + 统计特征全量（含泄漏，仅作上界） | 161.55 |
| D | 时间划分 + 统计特征置空（新题冷启动） | 442.42 |
| B′ | 随机划分 + 置空 + 训练集下采样至同规模 | 382.69 |
| S1′ | 时间划分 + 赛时统计（赛后立即可得，无泄漏） | 159.66 |

关键发现：S1′ 与 D 格**测试集完全一致**，其相对 D 格的下降（282.76 分）
经配对自助检验显著（95% CI [−293.46, −268.78]，不跨零）——
即新题误差的主要来源并非统计量的**累积时间**，而是这组行为统计**是否可得**。

## 复现注意事项

1. **随机性**：深度模型的种子只作用于训练，不改变划分；确定性模型（岭回归、核 SVR、
   标签均值基线）的标准差为 0。
2. **GPU 依赖**：BERT 与融合模型需要 CUDA；无 GPU 时可用 `--cpu` 跑传统模型部分。
3. **LLM 实验**：`outputs/llm/` 已含全部评分结果，无需重新调用 API 即可复现一致性分析；
   如需重跑，接口与密钥需自行配置（本仓库不含任何密钥）。
4. **B′ 与 S1′ 两档**只有 3 个种子，其余格为 5 个——表注已注明。
